# Phase 0 · Threat model (STRIDE, first pass)

Assets: tenant data, opaque audience refs, participation tokens, MADP/SampTrek credentials, consent state, quota
integrity, reward events, AI budgets, survey-owner authorizations, synthetic results, audit log.

Trust boundaries: browser ↔ web/API · Supply360 ↔ MADP · SampTrek ↔ Supply360 (webhooks, S2S callbacks, respondent
redirects from the public internet) · Supply360 ↔ SampIntel · SampIntel workers ↔ allowlisted survey hosts · apps ↔
AI providers.

| #   | Threat                                                          | Where                                               | Mitigation (built in the phase noted)                                                                                                                                        |
| --- | --------------------------------------------------------------- | --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S1  | Forged SampTrek webhook or S2S callback inflates completes      | Inbound webhooks                                    | HMAC verification, ±300 s window, event-id dedup in inbox, outcome must match an issued token for that project/market (P2, P5)                                               |
| S2  | Stolen session / account takeover                               | Web                                                 | OIDC + MFA, short sessions, re-auth for consequential actions, device/session list (P1)                                                                                      |
| S3  | Service credential leak (MADP secret, `pjx_` key)               | API config                                          | Secret manager, never in DB plaintext or logs, rotation runbook, least scopes (no `finance:read`) (P1, P8)                                                                   |
| T1  | Participation token tampering / guessing                        | Survey links                                        | 256-bit random opaque tokens, server lookup, expiry, no PII in URL, one token per invitation (P4)                                                                            |
| T2  | Replay of old events                                            | Inbox                                               | Unique `(source, event_id)`, nonce cache, idempotent transitions (P2, P5)                                                                                                    |
| T3  | Survey content prompt-injects the QA model or Copilot           | SampIntel, Copilot                                  | Content tagged untrusted, no tools with side effects, schema-validated outputs, secrets never in prompts, injection eval set (P6, P7)                                        |
| R1  | Actor denies launching a batch or changing a quota              | All                                                 | Append-only audit with actor, reason code, policy version, approval id (P1+)                                                                                                 |
| I1  | Cross-tenant data leak                                          | DB, cache, jobs, exports                            | RLS, tenant-scoped keys/jobs/paths, cross-tenant test suite in CI (P1)                                                                                                       |
| I2  | PII / health data reaches Supply360 or an AI provider           | MADP boundary, gateway                              | Only refs and counts accepted; schema rejects extra fields; gateway redaction; sensitive targeting only with purpose + role; small-cell suppression honoured (P3, P7)        |
| I3  | Open redirect / SSRF                                            | Redirect endpoints, SampIntel browser, webhook URLs | Redirect allowlists per project; outbound URL allowlist + DNS-rebinding-safe resolver; no private IP ranges (P2, P6)                                                         |
| I4  | Spreadsheet formula injection in exports                        | Exports                                             | Prefix `= + - @` and tab/CR cells; content-disposition; signed expiring links (P5, P7)                                                                                       |
| D1  | Runaway automation over-invites / spams panelists               | Dispatch                                            | Daily caps, batch caps, quiet hours, frequency caps re-checked at dispatch, global + project kill switch, circuit breaker on MADP errors (P4)                                |
| D2  | Webhook flood                                                   | Inbound                                             | Rate limits per source, queue backpressure, DLQ (P2)                                                                                                                         |
| D3  | AI budget exhaustion                                            | Gateways                                            | Budget checked before each call at worker level; hard stop + alert (P6)                                                                                                      |
| E1  | Role escalation (Executive acts as Supply Head)                 | API                                                 | Server-side RBAC/ABAC on every route, approval cannot be granted by requester (P1, P4)                                                                                       |
| E2  | Synthetic worker reaches human tokens/identities                | SampIntel                                           | Separate app, DB, credentials, network policy; no Supply360 token scopes issued to SampIntel (P6)                                                                            |
| X1  | SampIntel misused against surveys without authorization (fraud) | SampIntel                                           | Authorization record required, endpoint allowlist, expiry/revocation, test links default, stop on any security challenge; no IP rotation or detection evasion by design (P6) |

Privacy: MHO/health and minors are purpose-restricted in MADP; Supply360 never requests health criteria for
selection (MADP refuses them in `match` today). Retention defaults and deletion jobs defined per table in Phase 1.
Incident response, monitoring and restore drills are Phase 8 runbooks.
