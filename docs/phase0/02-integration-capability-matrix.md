# Phase 0 · Integration capability matrix and gaps

Legend: ✅ exists (verified in source/docs, DEMO or not live) · 🔶 partial · ❌ missing · ⛔ blocked (no access).
"Proposed" contracts are **proposals only**, written in `contracts/proposed/` once the repos exist; none is claimed as
an existing endpoint. Until each row is verified against a running system, Supply360 uses a **local fixture adapter**
labelled `FIXTURE` in data, API responses and UI.

## A. Supply360 ← SampTrek (project source)

| Spec need (§4, §8)                                 | SampTrek today                                                                                     | Status | Supply360 plan / proposed addition                                                                                                                                                                                                                                       |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Authenticated machine access                       | `pjx_` API key, scopes                                                                             | ✅     | Request `projects:read sessions:read quotas:read` only                                                                                                                                                                                                                   |
| Import projects (polling/backfill)                 | `GET /public/projects?updatedSince` + cursor                                                       | ✅     | Poller with checkpoint; uniqueness `(tenant, source, sourceProjectId)`                                                                                                                                                                                                   |
| Push on create/update                              | `project.created` only on SampAudience channel; public webhooks have `project.status_changed` only | 🔶     | Use status webhook + polling; **propose** `project.updated` public webhook (versioned)                                                                                                                                                                                   |
| Pause/closure overrides local automation           | `project.status_changed` (HOLD/CLOSED) signed                                                      | ✅     | Inbox → immediate dispatch stop                                                                                                                                                                                                                                          |
| Approved survey links                              | Vendor entry links are deliberately never returned by the public API                               | 🔶     | Supply360 is added **as a vendor** to the project; its entry link is entered/approved in Supply360 by a PM until SampTrek exposes the vendor's own link to that vendor (**propose** `GET /public/projects/{ref}/vendor-links/{linkId}/entry` scoped to the key's vendor) |
| Countries, target N, LOI, IR, dates, status, owner | Project + markets                                                                                  | ✅     | Mapped per market                                                                                                                                                                                                                                                        |
| Quotas                                             | `GET …/quotas` (cells from gate/prescreener answers)                                               | ✅     | Cells mapped to MADP attributes by a person (same pattern as SampTrek's SampAudience quota map); unmapped cells block launch                                                                                                                                             |
| Profiling requirements / targeting                 | Free text only (`targeting.naturalLanguage` on audience requests)                                  | 🔶     | Never inferred: AI may suggest, a person approves                                                                                                                                                                                                                        |
| Redirect configuration                             | Vendor redirect URLs per 8 statuses, macros                                                        | ✅     | Supply360 publishes its own redirect endpoints for SampTrek's vendor config                                                                                                                                                                                              |
| Participation outcomes                             | Signed S2S vendor callback `{uid}{status}` + redirects                                             | ✅     | Primary verified source of start/complete/terminate/etc.                                                                                                                                                                                                                 |
| Repeat restrictions                                | Cross-project fraud rules (internal)                                                               | 🔶     | Enforced on Supply360 side using MADP contact history; **propose** exposure                                                                                                                                                                                              |
| Approved reward reference                          | —                                                                                                  | ❌     | Configured per project in Supply360 with approval; **propose** field                                                                                                                                                                                                     |
| Final client approved/rejected (reconciliation)    | `GET …/sessions?outcomeSince` includes approval                                                    | ✅     | Poll after reconciliation; no SampTrek change needed                                                                                                                                                                                                                     |

## B. Supply360 ↔ MADP (audience, consent, delivery, rewards)

| Spec need (§5, §8)                                                                                                       | MADP today (`/api/v1/supply360/*`)                                    | Status    | Plan / proposed addition                                                                                                                                                                           |
| ------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------- | --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Signed service auth, scopes, idempotency                                                                                 | HMAC v1 + nonce + idempotency-key                                     | ✅ (DEMO) | Implement client exactly as documented                                                                                                                                                             |
| Attribute metadata: stable IDs, types, localized labels, options, **operators**, **version**, sensitivity, access policy | `GET attributes`: keys + categories only                              | 🔶        | **Propose** `GET attributes?version` returning the full descriptor; Supply360 renders whatever is returned (no hard-coded lists)                                                                   |
| Nested AND/OR/NOT, ranges, missing/unknown                                                                               | Flat AND of `{key, values[]}` (OR within), max 10                     | 🔶        | Filter builder compiles to MADP's flat form when expressible; anything else is **rejected with a reason** until MADP supports a **proposed** `criteria` tree (v2)                                  |
| Counts: unique vs memberships, small-cell suppression                                                                    | `POST counts`                                                         | ✅        | Shown distinctly                                                                                                                                                                                   |
| Selection with opaque refs, dedup across panels                                                                          | `POST match` (per-client `ref_…`, cross-panel identity in MADP)       | ✅        | Paginated by repeated match with `projectRef`; **propose** server-side selection token + cursor                                                                                                    |
| Recent-participant / cross-project suppression                                                                           | Contact caps + "held for another project"                             | 🔶        | Supply360 also suppresses from its own participation history per ref                                                                                                                               |
| Reservations                                                                                                             | `reservations` (≤14 d)                                                | ✅        | Mirrored by local atomic quota reservations                                                                                                                                                        |
| Recheck consent/eligibility at dispatch                                                                                  | `consent/check`, `invitations/authorize`                              | ✅        | Called immediately before every batch and reminder                                                                                                                                                 |
| **Send** invitation (email/SMS/push/WhatsApp, branded)                                                                   | Authorize records only; comms are dry-run only (`dryRun:false` → 403) | ❌        | **Blocker for real sends.** **Propose** `POST invitations/dispatch` + delivery status callbacks. Until then Supply360 runs dispatch against a fixture delivery adapter (nothing leaves the system) |
| Delivery / bounce / ack events                                                                                           | —                                                                     | ❌        | **Propose** signed `delivery.*` webhooks to Supply360                                                                                                                                              |
| Click tracking                                                                                                           | Accepts `click` event from Supply360                                  | ✅        | Supply360 owns tracked links (signed opaque token, no PII) and reports clicks to MADP                                                                                                              |
| Participation events                                                                                                     | `participation/events`                                                | ✅        | Forwarded idempotently                                                                                                                                                                             |
| Reminders                                                                                                                | "Not built"                                                           | ❌        | Supply360 schedules; dispatch via the proposed endpoint                                                                                                                                            |
| Reward events + acknowledgement                                                                                          | Loyalty `survey-approvals` is admin-session only                      | ❌        | **Propose** `POST supply360/reward-events` (idempotent, eligible completes only) + ack; Supply360 never credits wallets                                                                            |
| Integration health                                                                                                       | `integrations/health`                                                 | ✅        | Shown on Integration Health                                                                                                                                                                        |
| Live data                                                                                                                | All panels DEMO                                                       | ⛔        | Everything stays DEMO/FIXTURE until MADP goes live                                                                                                                                                 |
